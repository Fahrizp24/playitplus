# Voice Dummy Audio Presets (PlayItPlus)

Folder ini berisi berkas suara dummy untuk simulasi konsultasi klinis langsung dari antrean pasien SIMRS:

1. `preset-1.wav` (atau `.mp3` / `.webm`) -> **Audio Simulasi 1**
   - Default: Konsultasi Penyakit Dalam (Hipertensi & Diabetes Melitus).
2. `preset-2.wav` (atau `.mp3` / `.webm`) -> **Audio Simulasi 2**
   - Default: Konsultasi Poli Umum (Dispepsia & Asam Lambung / GERD).

Anda dapat menimpa (*overwrite*) berkas `preset-1.wav` dan `preset-2.wav` dengan berkas audio rekaman asli Anda kapan saja.
